# MCP Servers

## Installed Servers
| Server | Purpose | When to Use |
|--------|---------|-------------|
| server-memory | Persist context across sessions | Store project notes, decisions, key findings |
| server-github | GitHub API integration | PRs, issues, repo operations |
| server-fetch | HTTP client | Documentation lookups, API testing |
| server-sequential-thinking | Structured reasoning | Architecture decisions, complex debugging |
| server-exa | AI-powered web search | Research, market analysis, finding docs |
| server-shadcn | shadcn/ui components | Building UIs with shadcn |
| server-alpaca | Alpaca Trading API | Stock/ETF trading, portfolio management (paper mode) |

## Usage Priority
1. Use server-memory to persist important findings
2. Use server-sequential-thinking for complex multi-step problems
3. Use server-alpaca for real market data when available
4. Use server-fetch for API testing and doc lookups
